# RAG-based-Personalized-Recipe-Meal-Recommender-
NutriGenie AI - is an intelligent, personalized meal recommendation system built with Streamlit]  and LangChain, powered by Groq's LLM API.   It takes a user's health profile and a custom recipe dataset, then generates **tailored meal recommendations** with nutritional analysis, dietary guidelines, ingredient substitutions, and justifications.
